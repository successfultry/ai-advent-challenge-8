# AI Advent Challenge #8

Personal submissions repo. Python 3.12 + [uv](https://docs.astral.sh/uv/).

## Layout

```
week_XX/
  main.py        ← entrypoint
  cli.py         ← terminal UI
  client.py      ← API logic
  config.py      ← providers/models
  README.md      ← week description + daily progress
```

## Run

```bash
uv sync              # install deps
uv run python week_01/main.py   # run current week
```
